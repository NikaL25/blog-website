# Blog - Modern News & Blog Website

A clean, modern, and fully functional blog/news website built with HTML, CSS, and vanilla JavaScript.


## ✨ Features

- **Fully Responsive Design** – Works perfectly on mobile, tablet, and desktop
- **Working Search** – Real-time search across all articles (title, description, category)
- **Dynamic Content** – All posts loaded from `data.json`
- **Detail Pages** – Click on any post to read full article
- **Load More** – Pagination with "Load More" button
- **Fixed Burger Menu** – Smooth open/close with overlay
- **Modern UI/UX** – Clean design with smooth animations and hover effects
- **SEO Friendly** – Proper semantic HTML structure



## 🛠 How to Run the Project

1. **Download / Clone** 
```
git clone https://github.com/NikaL25/blog-website.git
```

```
cd blog-website
```
2. Open `index.html` in your browser (recommended: **Live Server** in VS Code)
3. Make sure all folders (`images`, `css`, `js`) are in the correct place

> **Note**: For full functionality (search, load more, detail pages), use **Live Server** (not just opening the HTML file directly).

## 📁 Files Description

| File                | Description |
|---------------------|-----------|
| `index.html`        | Main homepage |
| `detail-view.html`  | Single article page |
| `data.json`         | All blog posts data |
| `style.css`         | Main styles |
| `main.js`           | All JavaScript logic (search, menu, load more, etc.) |
| `detail.css`        | Styles for article page |

## 🔧 Main Functionalities

- **Search**: Press the search icon → type to see instant results
- **Navigation**: Working burger menu with smooth scroll
- **Reading Articles**: Click on any post title/image to open full article
- **Load More**: Dynamically loads more posts without page refresh
